✅ ငွေရပါပြီ — ကျေးဇူးတင်ပါတယ်

  1. App ကနေ ဝယ်ထားရင် Code ကို app ထဲ အလိုလို ထည့်ပြီးပါပြီ
  2. မဟုတ်ရင် App ရဲ့ Settings → Myanmar Flow Code မှာ Paste လုပ်ပြီး Save နှိပ်ပါ
  3. App မရှိသေးရင် ဒီမှာ Download လုပ်ပါ
