မေးလေ့ရှိတာတွေ

သိချင်တာ ရှိသေးလား

မဝယ်ခင် အခမဲ့ စမ်းလို့ရလား

ရပါတယ်။ App ကို install လုပ်ပြီး Setup wizard (ဒါမှမဟုတ် tray menu) က 🎁 အခမဲ့ ၅ မိနစ် စမ်းမယ် ကို နှိပ်ရုံပါပဲ — ၅ မိနစ် (message ၃၀ လောက်) ပါတဲ့ Code က အလိုလို ဝင်လာပါမယ်။ စက်တစ်လုံးကို တစ်ခါ ရပါတယ်။ ကြိုက်ရင် အဲဒီ Code ကိုပဲ ငွေဖြည့်ပြီး ဆက်သုံးလို့ရပါတယ်။

ငွေလွှဲပြီး Code ကို ဘယ်လောက်ကြာမှ ရလဲ

ချက်ချင်းပါပဲ။ ငွေလွှဲပြီး screenshot ထည့်လိုက်ရင် စက္ကန့်ပိုင်းအတွင်း စစ်ပြီး Code ကို page မှာ ပြပါတယ်။ ဘယ်သူ့ကိုမှ စာပို့စရာ မလိုပါ။ Screenshot မရှင်းရင် (ဥပမာ Transaction ID မပါရင်) လူကိုယ်တိုင် စစ်ပြီးမှ ပေးတာမို့ နည်းနည်း ကြာနိုင်ပါတယ်။

Code နဲ့ဆိုရင် VPN တကယ် မလိုတာလား

မလိုပါဘူး။ Code နဲ့ဆိုရင် app က Crash Flow server ကို ပို့ပြီး server က Google ကို ဆက်ပေးလို့ မြန်မာပြည်ထဲကနေ VPN မဖွင့်ဘဲ သုံးလို့ရပါတယ်။ ကိုယ်ပိုင် key နဲ့ သုံးမှသာ VPN လိုပါတယ်။

မိနစ်ကို ဘယ်လို တွက်လဲ

ပြောတဲ့ အသံ အရှည်အတိုင်း စက္ကန့်အထိ တိတိကျကျ တွက်ပါတယ်။ ၁၀ စက္ကန့် ပြောရင် ၁၀ စက္ကန့်ပဲ လျော့ပါတယ်။ AI စာပြင် ဒါမှမဟုတ် English ဘာသာပြန် ဖွင့်ထားရင် တစ်ကြိမ်ကို ၅ စက္ကန့် ထပ်တွက်ပါတယ်။

Code သက်တမ်း ဘယ်လောက်လဲ

များများဝယ်လေ ကြာကြာ သုံးလို့ရလေပါ — ၆၀ မိနစ်အောက် ၁၅ ရက်၊ ၁ နာရီကနေ ၃ နာရီအောက် ၁ လ၊ ၃ နာရီနဲ့ အထက် ၃ လ။ ငွေဖြည့်တိုင်း သက်တမ်း ပြန်စပြီး ကျန်နေတဲ့ မိနစ်တွေ အားလုံး ဆက်သုံးလို့ရပါတယ်။ သက်တမ်းကုန်သွားရင်လည်း Code အဟောင်းကိုပဲ ဖြည့်လိုက်ရင် ကျန်ခဲ့တဲ့ မိနစ်တွေ ပြန်ရပါတယ်။ အခမဲ့ စမ်း Code က ၇ ရက်ပါ။

Code တစ်ခုကို စက်ဘယ်နှလုံးမှာ သုံးလို့ရလဲ

ကိုယ့်စက်တွေ (ဥပမာ Desktop နဲ့ Laptop) မှာ Code တစ်ခုတည်း ထည့်သုံးလို့ရပါတယ်။ မိနစ်ကတော့ အတူတူ လျော့ပါမယ်။ Code ကို တခြားသူကို မပေးပါနဲ့ — သူတို့ သုံးရင် ကိုယ့်မိနစ် ကုန်ပါမယ်။

ပြောတဲ့စာတွေကို သိမ်းထားလား

မသိမ်းပါဘူး။ အသံကို Google ဆီ စာပြောင်းဖို့ ပို့ပြီး ထွက်လာတဲ့စာကို ကိုယ့်စက်ကိုပဲ ပြန်ပို့ပါတယ်။ Server က ဘယ်နှစက္ကန့် သုံးလဲ ဆိုတာပဲ မှတ်ပါတယ်။ Code အားလုံး GitHub မှာ ပွင့်လင်းလို့ ကိုယ်တိုင် စစ်ကြည့်လို့ရပါတယ်။

မိနစ်ကုန်သွားရင် ဘာဖြစ်မလဲ

App က "မိနစ် ကုန်သွားပါပြီ - ငွေဖြည့်ပါ" လို့ ပြပါမယ်။ App ထဲက 💳 မိနစ် ဝယ်မယ် ဒါမှမဟုတ် ဒီ website ကနေ ငွေဖြည့်ရင် Code အဟောင်းကိုပဲ ချက်ချင်း ဆက်သုံးလို့ရပါတယ်။ ဘာမှ ပြန်ထည့်စရာ မလိုပါ။

Burmese စာ ဘယ်လောက် မှန်လဲ
