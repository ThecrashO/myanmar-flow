ဘာတွေ လုပ်ပေးလဲ

Keyboard နဲ့ ရိုက်စရာ မလိုတော့ဘူး

  • ⚡ ပြောနေတုန်း စာတန်းပေါ်လွှတ်ပြီး ၀.၃ စက္ကန့်လောက်နဲ့ စာဝင်ပါပြီ။
  • 🌐 မြန်မာလိုပြော၊ English စာထွက်ညာဘက် Alt (Mac မှာ Command) ကိုဖိပြီး ပြောရင် English လို ရိုက်ပေးပါတယ်။
  • 🗣 Shortcut နဲ့ စာလုံးပြင်"ငါ့လိပ်စာ" လို့ ပြောရင် လိပ်စာအပြည့် ဝင်။ အမြဲမှားတဲ့ စာလုံးကို အမြဲမှန်အောင် ပြင်ထားလို့ရ။
  • 🔒 ပြောတဲ့စာကို မသိမ်းပါစာက ကိုယ့်စက်ထဲပဲ ရှိပါတယ်။ Code server က မိနစ်ပဲ မှတ်ပါတယ်။
ညာ Ctrlဖိထားပြီး ပြော → မြန်မာစာ ညာ Altဖိထားပြီး ပြော → English စာ Ctrl × ၂၂ ချက်ဆက်နှိပ်ရင် လက်လွှတ်ပြီး အရှည်ပြောလို့ရ

Mac မှာ Ctrl အစား ညာဘက် Option၊ Alt အစား ညာဘက် Command ကို သုံးပါ။ Settings မှာ ပြောင်းလို့ရပါတယ်။

Shortcut နဲ့ စာလုံးပြင်

အတိုလေး ပြော၊ အရှည်ကြီး ထွက်

လိပ်စာ၊ ဖုန်းနံပါတ်၊ ဘဏ်အကောင့် လို ခဏခဏ ရိုက်ရတာတွေကို စကားလုံး တစ်လုံးတည်းနဲ့ ထည့်လို့ရပါတယ်။ Tray icon → 📝 စကားလုံးနဲ့ Shortcut... မှာ ထည့်ပါ။

ပြောတာ"ငါ့လိပ်စာ ကို ပို့ပေး"
ဝင်လာတာအမှတ် ၁၂၊ ဗိုလ်ချုပ်လမ်း၊ ရန်ကုန် ကို ပို့ပေး

🗣 Shortcut — အတိုပြော၊ အရှည်ထွက်

စကားစု တိုတိုလေး ပြောလိုက်ရင် သတ်မှတ်ထားတဲ့ စာအရှည် ဝင်လာပါမယ်။ တစ်ခုတည်း ပြောရင်ရော၊ စာကြောင်းထဲ ညှပ်ပြောရင်ပါ ရပါတယ်။

Code နဲ့ စသုံးနည်း

ဝယ်ပြီး ၅ မိနစ်အတွင်း စသုံးလို့ရ

  1. Code ယူပါဒီမှာ (ဒါမှမဟုတ် app ထဲက 💳 မိနစ် ဝယ်မယ်) မိနစ် ရွေးပြီး KBZPay / WavePay နဲ့ ပေးပါ။ Screenshot ထည့်လိုက်ရင် Code ကို ချက်ချင်း ရပါမယ်။ အရင် စမ်းချင်ရင် app ထဲက 🎁 အခမဲ့ ၅ မိနစ် ကို နှိပ်ပါ။
  2. App ကို Install လုပ်ပါ Windows: MyanmarFlow-Setup.exe · Mac (M1/M2/M3/M4): MyanmarFlow-mac.zip · Mac (Intel): MyanmarFlow-mac-intel.zip
    Windows မှာ အပြာရောင် box ပေါ်ရင် More info → Run anyway ကို နှိပ်ပါ (သတိပေးချက်ပဲပါ၊ ဘာမှ မဖြစ်ပါဘူး)။
    Mac မှာ "MyanmarFlow Not Opened" ပေါ်ရင်
    စိတ်မပူပါနဲ့ — ဒါက သတိပေးချက်ပဲပါ။ App မှာ ပြဿနာရှိလို့ ပေါ်တာ မဟုတ်ပါဘူး။ Apple ကို တစ်နှစ် $99 ပေးပြီး စစ်ဆေးခိုင်း (notarize) မထားတဲ့ app တိုင်းမှာ ဒီစာ ပေါ်ပါတယ်။ Open Anyway နှိပ်လို့ ကိုယ့် Mac ကို ဘာမှ မဖြစ်စေပါဘူး။
    1. Zip ကိုဖွင့်ပြီး MyanmarFlow ကို Applications folder ထဲ ဆွဲထည့်ပါ
    2. "Apple could not verify…" box ပေါ်ရင် Move to Trash မနှိပ်ပါနဲ့၊ Done ကို နှိပ်ပါ
    3. ဘယ်ဘက်အပေါ်ထောင့်က Apple မီနူး → System Settings → Privacy & Security ကိုသွားပြီး အောက်ဆုံးနားက Open Anyway ကို နှိပ်ပါ
    4. Mac password (ဒါမှမဟုတ် Touch ID) ထည့်ပြီး Open ကို နှိပ်ပါ
    5. App ပွင့်လာရင် Privacy & Security → Accessibility မှာ MyanmarFlow ကို ဖွင့်ပေးပြီး app ကို ပိတ်ပြီး ပြန်ဖွင့်ပါ (key ဖိတာ သိဖို့)။ Mic ကို ပထမဆုံး ပြောတဲ့အခါ Allow နှိပ်ပါ
    တစ်ခါပဲ လုပ်ရပါတယ်။ နောက်ပိုင်း ပုံမှန်အတိုင်း ပွင့်ပါမယ်။ (ဘာလို့ ဒီစာ ပေါ်တာလဲ)
  3. Code ကို ထည့်ပါSetup wizard ပွင့်လာရင် key ထည့်တဲ့ အကွက်ထဲမှာ Code ကို Paste လုပ်ပြီး စစ်ဆေးမယ် နှိပ်ပါ။ (Settings → Myanmar Flow Code မှာလည်း ထည့်လို့ရ)
  4. Mic စမ်းပြီး စပြောပါ"မင်္ဂလာပါ" လို့ ပြောကြည့်ပါ။ စာပေါ်လာရင် အဆင်သင့် ဖြစ်ပါပြီ။
  5. လက်ကျန် ကြည့်ပြီး ငွေဖြည့်ပါTray (Mac မှာ menu bar) icon ကို နှိပ်ရင် ⏳ လက်ကျန် ကို မြင်ရပါမယ်။ ၁၀ မိနစ်အောက် ရောက်ရင် app က အသိပေးပါမယ်။

ရပါတယ်။ App ကို install လုပ်ပြီး Setup wizard (ဒါမှမဟုတ် tray menu) က 🎁 အခမဲ့ ၅ မိနစ် စမ်းမယ် ကို နှိပ်ရုံပါပဲ — ၅ မိနစ် (message ၃၀ လောက်) ပါတဲ့ Code က အလိုလို ဝင်လာပါမယ်။ စက်တစ်လုံးကို တစ်ခါ ရပါတယ်။ ကြိုက်ရင် အဲဒီ Code ကိုပဲ ငွေဖြည့်ပြီး ဆက်သုံးလို့ရပါတယ်။

ငွေလွှဲပြီး Code ကို ဘယ်လောက်ကြာမှ ရလဲ

ချက်ချင်းပါပဲ။ ငွေလွှဲပြီး screenshot ထည့်လိုက်ရင် AI က စက္ကန့်ပိုင်းအတွင်း စစ်ပြီး Code ကို page မှာ ပြပါတယ်။ ဘယ်သူ့ကိုမှ စာပို့စရာ မလိုပါ။ Screenshot မရှင်းရင် (ဥပမာ Transaction ID မပါရင်) လူကိုယ်တိုင် စစ်ပြီးမှ ပေးတာမို့ နည်းနည်း ကြာနိုင်ပါတယ်။

Code နဲ့ဆိုရင် VPN တကယ် မလိုတာလား

မလိုပါဘူး။ Code နဲ့ဆိုရင် app က Myanmar Flow server ကို ပို့ပြီး server က Google ကို ဆက်ပေးလို့ မြန်မာပြည်ထဲကနေ VPN မဖွင့်ဘဲ သုံးလို့ရပါတယ်။ ကိုယ်ပိုင် key နဲ့ သုံးမှသာ VPN လိုပါတယ်။

မိနစ်ကို ဘယ်လို တွက်လဲ

ပြောတဲ့ အသံ အရှည်အတိုင်း စက္ကန့်အထိ တိတိကျကျ တွက်ပါတယ်။ ၁၀ စက္ကန့် ပြောရင် ၁၀ စက္ကန့်ပဲ လျော့ပါတယ်။ AI စာပြင် ဒါမှမဟုတ် English ဘာသာပြန် ဖွင့်ထားရင် တစ်ကြိမ်ကို ၅ စက္ကန့် ထပ်တွက်ပါတယ်။

Code သက်တမ်း ဘယ်လောက်လဲ

များများဝယ်လေ ကြာကြာ သုံးလို့ရလေပါ — ၆၀ မိနစ်အောက် ၃၀ ရက်၊ ၁ နာရီကနေ ၃ နာရီအောက် ၉၀ ရက်၊ ၃ နာရီနဲ့ အထက် ၁ နှစ်။ ငွေဖြည့်တိုင်း သက်တမ်း ပြန်စပြီး ကျန်နေတဲ့ မိနစ်တွေ အားလုံး ဆက်သုံးလို့ရပါတယ်။ သက်တမ်းကုန်သွားရင်လည်း Code အဟောင်းကိုပဲ ဖြည့်လိုက်ရင် ကျန်ခဲ့တဲ့ မိနစ်တွေ ပြန်ရပါတယ်။ အခမဲ့ စမ်း Code က ၇ ရက်ပါ။

Code တစ်ခုကို စက်ဘယ်နှလုံးမှာ သုံးလို့ရလဲ

ကိုယ့်စက်တွေ (ဥပမာ Desktop နဲ့ Laptop) မှာ Code တစ်ခုတည်း ထည့်သုံးလို့ရပါတယ်။ မိနစ်ကတော့ အတူတူ လျော့ပါမယ်။ Code ကို တခြားသူကို မပေးပါနဲ့ — သူတို့ သုံးရင် ကိုယ့်မိနစ် ကုန်ပါမယ်။

ပြောတဲ့စာတွေကို သိမ်းထားလား

မသိမ်းပါဘူး။ အသံကို Google ဆီ စာပြောင်းဖို့ ပို့ပြီး ထွက်လာတဲ့စာကို ကိုယ့်စက်ကိုပဲ ပြန်ပို့ပါတယ်။ Server က ဘယ်နှစက္ကန့် သုံးလဲ ဆိုတာပဲ မှတ်ပါတယ်။

မိနစ်ကုန်သွားရင် ဘာဖြစ်မလဲ

App က "မိနစ် ကုန်သွားပါပြီ - ငွေဖြည့်ပါ" လို့ ပြပါမယ်။ App ထဲက 💳 မိနစ် ဝယ်မယ် ဒါမှမဟုတ် ဒီ website ကနေ ငွေဖြည့်ရင် Code အဟောင်းကိုပဲ ချက်ချင်း ဆက်သုံးလို့ရပါတယ်။ ဘာမှ ပြန်ထည့်စရာ မလိုပါ။

Burmese စာ ဘယ်လောက် မှန်လဲ

ပုံမှန်ပြောတဲ့ စကားကို အတော်လေး မှန်ပါတယ်။ နာမည်လို အမြဲမှားတဲ့ စာလုံးတွေကို "စကားလုံးနဲ့ Shortcut" မှာ တစ်ခါ ပြင်ထားရင် နောက်ပိုင်း အမြဲမှန်ပါမယ်။ Code မဝယ်ခင် အခမဲ့ ၅ မိနစ် Code နဲ့ (ဒါမှမဟုတ် ကိုယ်ပိုင် key နဲ့) စမ်းကြည့်လို့ ရပါတယ်။

ဘယ်စက်တွေမှာ သုံးလို့ရလဲ

Windows 10/11 နဲ့ macOS 14 (Sonoma) နောက်ပိုင်း Mac တွေပါ — Apple Silicon (M1–M4) ရော Intel Mac ရော ရပါတယ်။ ဖုန်းမှာတော့ မရသေးပါ။

Install လုပ်တုန်း သတိပေးစာ ပေါ်တာ အန္တရာယ်ရှိလား

မရှိပါဘူး၊ သတိပေးချက်ပဲပါ။ Mac မှာ "Apple could not verify…"၊ Windows မှာ "Windows protected your PC" ဆိုတဲ့ စာက Apple နဲ့ Microsoft ကို ပိုက်ဆံပေးပြီး လက်မှတ် မထိုးထားတဲ့ app တိုင်းမှာ ပေါ်တာပါ။ App ထဲမှာ virus တွေ့လို့ ပြတာ မဟုတ်ပါဘူး။ Myanmar Flow ရဲ့ code အားလုံးကို GitHub မှာ ဘယ်သူမဆို ကြည့်လို့ရပြီး Windows နဲ့ Mac app တွေကိုလည်း အဲဒီ code ကနေ GitHub ပေါ်မှာ တိုက်ရိုက် build လုပ်ထားတာပါ။ Mac မှာ Done → Open Anyway၊ Windows မှာ More info → Run anyway ကို နှိပ်ရုံပါပဲ။ တစ်ခါပဲ လုပ်ရပါတယ်။
